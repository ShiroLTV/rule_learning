# 不法行為法を学ぶ

民法の不法行為（第709条〜第724条の2）を、読む資料・図・選択問題・〇×クイズで学ぶページです。`index.html` をブラウザで開くと使えます。

- 中身のデータ：`data/tort-data.json`（同じ内容を `data/tort-data.js` でも持っています。直すときは両方そろえます）
- 実際の事件の判断は事実関係によって変わります。具体的な相談は弁護士などの専門家にしてください。
